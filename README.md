One deadpan one-star review of sleep, filed in a single line of at most 160 characters: it takes a third of every day, cannot be banked or caught up, and still wakes you twenty minutes before the alarm you set to end it. The program writes the review to /output/entry.txt; the review is the entry.

## Run it

```sh
node main.ts
```
